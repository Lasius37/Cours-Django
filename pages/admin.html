    Créer un superutilisateur

    Django possède une interface d’administration intégrée, qui permet de gérer rapidement les données de l’application sans créer tout de suite des pages HTML spécifiques. Elle est très utile pour :

    • ajouter des objets
    • modifier des objets
    • supprimer des objets
    • vérifier que les modèles et les relations fonctionnent correctement.

    C’est donc un outil pratique pour tester un projet Django et manipuler la base de données. Pour accéder à l’administration, il faut créer un compte administrateur. 

    python manage.py createsuperuser

    Django demande ensuite plusieurs informations :

    • un nom d’utilisateur
    • une adresse email (facultative selon les cas)
    • un mot de passe

    Ce compte permet de se connecter à l’interface d’administration du projet.

    Enregistrer un modèle

    Les modèles n’apparaissent pas automatiquement dans l’administration. Il faut les enregistrer dans le fichier admin.py de l’application. 

    from django.contrib import admin
from .models import Student, Classroom, Teacher


admin.site.register(Student)
admin.site.register(Classroom)
admin.site.register(Teacher)

    Une fois enregistrés, ces modèles deviennent visibles dans l’interface d’administration.

    Accéder à l’administration

    Une fois le superutilisateur créé et le serveur lancé, l’administration est accessible à l’adresse : 

    http://127.0.0.1:8000/admin/

    Après connexion, Django affiche la liste des modèles enregistrés.

    On peut alors ouvrir les sections Students, Classrooms et Teachers pour gérer les données.

    Gérer les données

    L’interface d’administration permet de créer et modifier facilement des objets. Par exemple :

    • ajouter une classe
    • ajouter plusieurs professeurs
    • ajouter des élèves
    • associer un élève à une classe
    • associer plusieurs professeurs à une classe

    Cela permet de tester rapidement les relations définies dans les modèles. L’administration constitue donc une première interface CRUD :

    • Create : créer un objet
    • Read : afficher les objets
    • Update : modifier un objet
    • Delete : supprimer un objet

    Personnaliser l’affichage

    L’enregistrement simple avec admin.site.register() est suffisant pour commencer. Mais on peut aussi améliorer l’affichage dans l’administration. 

    from django.contrib import admin
from .models import Student


@admin.register(Student)
class StudentAdmin(admin.ModelAdmin):
    list_display = ("last_name", "first_name", "classroom")
    search_fields = ("last_name", "first_name")
    list_filter = ("classroom",)

    Dans cet exemple :

    • list_display choisit les colonnes visibles
    • search_fields ajoute une barre de recherche
    • list_filter ajoute un filtre dans la colonne latérale

    Il est possible de personnaliser le nom affiché dans l’administration. Par défaut, Django utilise le nom du modèle (par exemple Students). On peut modifier ce nom avec la classe Meta dans le modèle. 

    from django.db import models


class Student(models.Model):
    ...
    class Meta:
        verbose_name = "Élève"  # nom affiché au singulier
        verbose_name_plural = "Élèves"  # nom affiché au pluriel

    Ces modifications ne sont pas obligatoire au début, mais rendent l’interface beaucoup plus pratique.

    Erreurs fréquentes

    • Oublier de créer un superutilisateur : impossible de se connecter à l’administration.
    • Oublier d’enregistrer un modèle dans admin.py : le modèle n’apparaît pas dans l’interface.
    • Oublier les migrations avant d’utiliser l’administration : la base de données n’est pas prête.
