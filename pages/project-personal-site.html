    Énoncé

    Vous devez réaliser un mini-site personnel avec Django.

    • Le site doit présenter une personne réelle ou fictive.
    • Le projet doit utiliser Django .
    • Le site contiendra au minimum 3 pages :
      • une page d’accueil
      • une page de présentation
      • une page de contact ou de centres d’intérêt
    • Chaque page est affichée avec une vue et un template HTML.
    • La navigation doit permettre de passer facilement d’une page à l’autre.
    • Les pages doivent partager une présentation cohérente (en-tête, navigation, pied, styles).
    • Le contenu doit comporter :
      • un titre clair
      • des textes structurés
      • au moins un fichier statique (une image)
      • des liens de navigation visibles
    • Le projet doit fonctionner avec le serveur de développement Django.

    Conseils de réalisation

    • Préparer l’arborescence du projet
    • Créer une application website
    • Créer les pages HTML nécessaires dans le dossier templates de l’application :
      • / ou /home/ : page d’accueil
      • /about/ : présentation
      • /contact/, /hobbies/, ... : page complémentaire
    • Créer les routes dans urls.py dans l’application.
    • Créer les vues nécessaires.
    • Réutiliser une structure commune avec un fichier base.html
    • Ajouter un dossier static contenant les images et les feuilles de style.
    • Soigner le contenu :
      • Présenter la personne choisie.
      • Ajouter quelques informations utiles : parcours, goûts, projets, compétences, loisirs.
      • Utiliser des titres, des paragraphes et éventuellement des listes.
      • Ajouter au moins une image pertinente.
    • Tester le projet avec un serveur Django, et vérifier que :
      • toutes les pages s’affichent
      • les liens fonctionnent
      • aucune erreur 404 ou TemplateDoesNotExist n’apparaît.
