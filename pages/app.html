    Pourquoi créer une application ?

    Dans Django, un projet correspond à l'ensemble du site, alors qu'une application correspond à une fonctionnalité précise.

    Une application permet de regrouper dans un même dossier :

    • les vues
    • les modèles
    • les routes propres à la fonctionnalité
    • les templates HTML
    • les fichiers d'administration

    Cette organisation rend le projet plus lisible et plus modulaire. On peut ainsi séparer, par exemple, la page d'accueil, les utilisateurs, le blog ou une API en plusieurs applications distinctes.

    Créer une application avec startapp

    Une application se crée avec la commande startapp, à lancer depuis le dossier contenant manage.py. 

    python manage.py startapp mon_app apps/mon_app

    Ici, mon_app est le nom de l'application, apps/mon_app est le dossier dans lequel Django crée ses fichiers. Attention, cette commande suppose que le dossier apps existe déjà.

    Après la création, Django génère automatiquement la structure de base de l'application. 

    apps/
└── mon_app/
    │
    ├── migrations/         contient l'historique des changements de la base de données.
    │   └── __init__.py     indique que le dossier est un package Python.
    │
    ├── __init__.py         indique que le dossier est un package Python.
    ├── admin.py            permet d'enregistrer les modèles dans l'administration Django.
    ├── apps.py             contient la configuration de l'application.
    ├── models.py           contient les classes représentant les données.
    ├── tests.py            permet d'écrire des tests.
    └── views.py            contient les vues qui répondront aux requêtes.

    Bien nommer une application

    Le nom d'une application doit être simple, court et lié à sa fonction.

    Bonnes pratiques :

    • utiliser des lettres minuscules
    • éviter les espaces et les tirets
    • choisir un nom fonctionnel
    • éviter un nom trop vague si le projet doit grandir

    Exemples corrects : 

    website
pages
blog
accounts
dashboard

    Exemples à éviter : 

    MonAppli
mon-app
app1
test
site web

    Une fois l'application créée, il faut encore l'intégrer au projet.

    Erreurs fréquentes

    • Créer une application sans se placer dans le dossier contenant manage.py : la commande échoue ou crée les fichiers au mauvais endroit.
    • Oublier de créer le dossier apps avant d'utiliser startapp avec un chemin : impossible de créer l'application dans le dossier visé.
    • Choisir un nom trop générique comme app ou test : nom peu clair.
    • Confondre le nom du projet et le nom de l'application : organisation confuse.
