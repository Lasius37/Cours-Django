    Créer le fichier forms.py

    Django propose un système de formulaires qui évite d’écrire tout le HTML et toute la logique à la main. Les formulaires sont généralement définis dans un fichier forms.py placé dans l’application. Ce fichier n’est pas créé automatiquement par Django lors du startapp : il faut donc l’ajouter manuellement. 

    apps/
└── mon_app/
    ├── forms.py        le fichier à ajouter
    ├── models.py
    ├── views.py
    └── templates/

    Créer un formulaire avec Form

    Pour créer un formulaire simple, on importe le module forms de Django, puis on définit une classe qui hérite de forms.Form. 

    from django import forms


class ContactForm(forms.Form):
    name = forms.CharField(max_length=100)
    email = forms.EmailField()
    message = forms.CharField(widget=forms.Textarea)

    Ici, le formulaire contient trois champs :

    • name : un texte court
    • email : une adresse email
    • message : un texte plus long grâce au widget Textarea

    Chaque champ est défini comme un attribut de la classe.

    Envoyer le formulaire à une vue

    Pour afficher un formulaire, la vue doit créer une instance du formulaire et l’envoyer au template dans le contexte. 

    from django.shortcuts import render
from .forms import ContactForm


def contact(request):
    context = {"form": ContactForm()}
    return render(request, "contact.html", context)

    Ici, la variable form est transmise au template avec render(). À ce stade, le formulaire est seulement affiché. Le traitement des données envoyées sera fait ensuite.

    Afficher le formulaire dans un template

    Dans le template, on place le formulaire à l’intérieur d’une balise <form>. 

    <form method="post">
    {% csrf_token %}
    {{ form }}
    <button type="submit">Envoyer</button>
</form>
    • method="post" indique que les données sont envoyées au serveur (requête de type POST)
    • {% csrf_token %} ajoute une protection de sécurité
    • {{ form }} affiche automatiquement tous les champs du formulaire

    Django peut aussi afficher le formulaire avec une mise en forme légèrement différente : 

    {{ form.as_p }}

    Chaque champ sera alors affiché dans une balise <p> HTML. La structure du formulaire est un peu plus lisible et moins "brute".

    Utiliser ModelForm

    Quand un formulaire doit être lié à un modèle Django, il est souvent plus pratique d’utiliser ModelForm plutôt que forms.Form. 

    from django import forms
from .models import Book


class BookForm(forms.ModelForm):
    class Meta:
        model = Book
        fields = ["title", "publication_year", "author", "categories"]

    Dans ce cas, Django crée automatiquement les champs du formulaire à partir du modèle.

    • model indique le modèle utilisé ;
    • fields indique les champs à afficher dans le formulaire.

    Cette solution est particulièrement utile pour créer ou modifier des objets liés à la base de données.

    Erreurs fréquentes

    • Oublier de créer le fichier forms.py : impossible d’importer le formulaire.
    • Oublier d’hériter de forms.Form ou forms.ModelForm : le formulaire ne fonctionne pas correctement.
    • Oublier d’importer from django import forms : NameError.
    • Oublier d’envoyer form dans le context de render() : rien ne s’affiche dans le template.
    • Oublier la balise <form> dans le template : le formulaire s’affiche, mais l’envoi n’est pas correct.
    • Oublier {% csrf_token %} dans un formulaire en POST : Django refuse la requête.
    • Utiliser un nom de champ inexistant dans fields d’un ModelForm : erreur de configuration.
