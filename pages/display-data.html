    Envoyer des données au template

    Dans une vue, les données sont récupérées puis transmises au template avec render(). 

    from django.shortcuts import render
from .models import Student, Teacher


def student_list(request):
    students = Student.objects.all()
    teacher = Teacher.objects.get(id=1)

    context = {"students": students, "teacher": teacher}

    return render(request, "students.html", context)
    • students = Student.objects.all() récupère les élèves.
    • teacher = Teacher.objects.get(id=1) récupère un enseignant.
    • context est un dictionnaire qui envoie les variables au template.
    • dans le template, les noms disponibles seront students et teacher.

    Afficher une variable

    Pour afficher une donnée dans un template, on utilise des doubles accolades. 

    <p>{{ teacher.last_name }} {{ teacher.first_name }}</p>

    Si le template reçoit un objet teacher, cette instruction affiche son nom et son prénom.

    Afficher plusieurs objets

    Quand le template reçoit plusieurs objets, on utilise une boucle {% for %}. 

    <ul>
    {% for student in students %}
        <li>{{ student.first_name }} {{ student.last_name }}</li>
    {% endfor %}
</ul>

    Cette boucle parcourt tous les objets contenus dans students et affiche une ligne pour chacun.

    Afficher une relation

    Si les modèles sont liés, le template peut accéder directement aux objets associés. 

    <ul>
    {% for student in students %}
        <li>
            {{ student.first_name }} {{ student.last_name }} - {{ student.classroom }}
        </li>
    {% endfor %}
</ul>

    Ici, on affiche aussi la classe de chaque élève. 

    <p>Classe : {{ student.classroom.level }}{{ student.classroom.letter }}</p>

    On peut donc afficher directement un champ lié, comme le niveau ou la lettre de la classe.

    Afficher selon une condition

    Un template Django peut afficher du contenu seulement si une condition est vraie. Pour cela, on utilise une structure {% if %}. 

    {% if student.classroom %}
    <p>Classe : {{ student.classroom }}</p>
{% endif %}

    Ici, la classe n’est affichée que si l’élève possède bien une classe associée. On peut aussi utiliser {% else %} pour prévoir un autre affichage, et éventuellement {% elif %} puis {% else %}, comme en Python. 

    {% if student.classroom %}
    <p>Classe : {{ student.classroom }}</p>
{% else %}
    <p>Aucune classe renseignée.</p>
{% endif %}

    Cette structure est utile pour gérer les données absentes ou afficher un contenu différent selon les cas.

    Gérer une liste vide

    Il est souvent utile de prévoir le cas où aucun objet n’est présent dans la base. 

    <ul>
    {% for student in students %}
        <li>{{ student.first_name }} {{ student.last_name }}</li>
    {% empty %}
        <li>Aucun élève enregistré.</li>
    {% endfor %}
</ul>

    Le bloc {% empty %} est exécuté si la liste est vide ; sa syntaxe est plus légère que {% if %} dans ce contexte.

    Erreurs fréquentes

    • Oublier d’envoyer la variable dans render() : le template ne peut pas l’utiliser.
    • Utiliser dans le template un nom différent de celui envoyé par la vue : rien ne s’affiche.
    • Oublier les doubles accolades {{ ... }} pour afficher une variable : la donnée n’apparaît pas.
    • Confondre {% ... %} et {{ ... }} : l’un sert aux instructions, l’autre à l’affichage.
    • Essayer d’accéder à une relation inexistante, par exemple student.room au lieu de student.classroom : erreur ou affichage vide.
    • Penser qu’un template interroge directement la base de données : c’est la vue qui prépare les données.
