Définition

Dans une application réelle, les données ne sont pas isolées. Un élève appartient à une classe, par exemple. Django permet de créer des relations entre les modèles pour représenter ces dépendances. Les deux relations les plus utilisées sont :

  • ForeignKey : plusieurs objets pointent vers un seul autre objet
  • ManyToManyField : plusieurs objets peuvent être liés entre eux dans les deux sens

Créer une relation avec ForeignKey

Une ForeignKey sert à relier plusieurs objets à un seul autre objet. Exemple : plusieurs élèves peuvent appartenir à une même classe. 

from django.db import models


class Classroom(models.Model):
    level = models.CharField(max_length=1)
    letter = models.CharField(max_length=1)

    def __str__(self):
        return f"{self.level}ème {self.letter}"


class Student(models.Model):
    first_name = models.CharField(max_length=50)
    last_name = models.CharField(max_length=50)
    classroom = models.ForeignKey(Classroom, on_delete=models.CASCADE)

    def __str__(self):
        return f"{self.last_name} {self.first_name}"

Chaque objet Student est lié à un seul objet Classroom. models.CASCADE signifie : si une classe est supprimée, tous les élèves liés à cette classe sont supprimés aussi.

Créer une relation avec ManyToManyField

Une relation ManyToManyField est utile quand plusieurs objets peuvent être liés à plusieurs autres objets. Exemple : une classe peut avoir plusieurs professeurs, et un professeur peut enseigner dans plusieurs classes. 

from django.db import models


class Teacher(models.Model):
    first_name = models.CharField(max_length=50)
    last_name = models.CharField(max_length=50)

    def __str__(self):
        return f"{self.last_name} {self.first_name}"


class Classroom(models.Model):
    level = models.CharField(max_length=1)
    letter = models.CharField(max_length=1)
    teachers = models.ManyToManyField(Teacher)

    def __str__(self):
        return f"{self.level}ème {self.letter}"

Django crée automatiquement une table intermédiaire pour gérer cette relation.

Accéder aux données liées

Une fois la relation créée, on peut accéder aux données liées très simplement. 

student = Student.objects.get(id=1)
student.classroom

Cette expression renvoie la classe liée à l'élève. 

student.classroom.level

On peut donc accéder directement aux champs de l’objet lié.

Interroger une relation

Les relations peuvent aussi être utilisées dans les requêtes. 

students = Student.objects.filter(classroom__level="6")

Le double underscore __ permet de traverser la relation. 

students = Student.objects.order_by("classroom__level", "last_name")

Ici, les élèves sont triés d’abord par niveau de classe, puis par nom.

Erreurs fréquentes

  • Oublier d’importer models : erreur Python.
  • Créer une relation puis oublier makemigrations et migrate : la base de données n’est pas mise à jour.
  • Utiliser un nom de modèle inexistant dans ForeignKey ou ManyToManyField : erreur au démarrage.
  • Oublier le paramètre on_delete dans ForeignKey : Django refuse le modèle.
  • Utiliser un mauvais nom de champ relationnel dans une requête, comme classroom__leve au lieu de classroom__level : FieldError.
