Fonctionnement d'une page Django

Lorsqu'un utilisateur ouvre une page dans son navigateur, Django suit plusieurs étapes. 

Navigateur
    ↓
URL (urls.py)
    ↓
Vue (views.py)
    ↓
Template (HTML)
    ↓
Page envoyée au navigateur

Le fichier urls.py permet d'associer une URL à une vue. C'est lui qui détermine quelle fonction doit être exécutée lorsqu'une page est demandée.

Configurer config/urls.py

Le projet possède un fichier principal de routes situé dans config/urls.py. On modifie ce fichier pour connecter les routes de l'application. 

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("apps.mon_app.urls")),   # include permet de déléguer les routes à l'application
]

Créer urls.py dans l'application

Chaque application peut posséder son propre fichier urls.py. Pour cela, on crée le fichier : 

apps/mon_app/urls.py

Puis on définit les routes de l'application. Ici, l'URL principale du site appelle la vue home. 

from django.urls import path
from . import views

urlpatterns = [
    path("", views.home),
]

Utiliser include()

La fonction include() permet de séparer les routes du projet et celles des applications.

  • Le projet délègue les routes principales : 
    path("", include("apps.mon_app.urls"))
  • L'application définit ensuite ses propres routes dans apps.mon_app.urls.

Cette organisation permet de garder un projet clair lorsque plusieurs applications sont utilisées.

Erreurs fréquentes

  • Oublier d'importer include : NameError.
  • Se tromper dans le chemin de l'application : ModuleNotFoundError.
  • Oublier de créer la vue appelée dans views.py : NameError.
  • Ne pas redémarrer le serveur après modification des routes.
