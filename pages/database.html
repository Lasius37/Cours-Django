Récupérer toutes les données

Une fois les modèles créés et les migrations appliquées, Django permet d'interroger la base de données. Ces requêtes se font à l'aide des QuerySets. Un QuerySet est une collection d'objets récupérés depuis la base de données. 

students = Student.objects.all()

Cette requête récupère tous les objets du modèle Student.

Récupérer un objet

Parfois, on cherche à récupérer un seul objet du modèle.

student = Student.objects.get(id=1)

Cette méthode permet de récupérer un seul objet (ici, par son identifiant id). Si aucun objet ou plusieurs objets correspondent, Django renvoie une erreur.

Filtrer les données

students = Student.objects.filter(age=14)

Cette requête retourne tous les élèves ayant 14 ans. Contrairement à get(), elle peut renvoyer plusieurs résultats. 

students = Student.objects.exclude(age=14)

Ce filtre permet d'exclure certains résultats.

Trier les résultats

students = Student.objects.order_by("last_name")

Ici, on trie les élèves par ordre alphabétique de leur nom.

students = Student.objects.order_by("-age")

Le signe - permet de trier en ordre inverse (décroissant dans ce cas).

Utilisation dans une vue

from django.shortcuts import render
from .models import Student


def student_list(request):
    students = Student.objects.all()
    return render(request, "students.html", {"students": students})

Les données sont ensuite accessibles dans le template.

Erreurs fréquentes

  • Oublier d'importer le modèle : NameError
  • Utiliser get() avec plusieurs résultats : erreur
  • Utiliser un mauvais nom de champ : FieldError
  • Oublier les migrations : table inexistante
