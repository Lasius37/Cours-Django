Lancer le serveur de développement

Django possède un serveur de développement intégré qui permet de tester rapidement un projet. La commande doit être exécutée depuis le dossier contenant manage.py. 

python manage.py runserver

Après l'exécution de la commande, le terminal affiche plusieurs informations : 

Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.

Cela signifie que le serveur est actif et que le projet est accessible dans le navigateur.

Pour arrêter le serveur de développement, il suffit d'utiliser le raccourci clavier : 

CTRL + C

Le terminal revient alors à l'invite de commande.

Ouvrir le site dans le navigateur

Une fois le serveur lancé, il suffit d'ouvrir l'adresse indiquée dans le navigateur : 

http://127.0.0.1:8000

Si tout fonctionne correctement, Django affiche une page de confirmation indiquant que l'installation est réussie. Cette page apparaît tant qu'aucune route personnalisée n'a été définie dans le projet.

Si le port 8000 est occupé, on peut utiliser un autre port : 

python manage.py runserver 8001

Le serveur de développement recharge automatiquement le projet lorsque des fichiers Python sont modifiés. Cela permet de tester immédiatement les modifications sans redémarrer le serveur. Par exemple, après avoir modifié une vue ou un fichier de configuration, il suffit d'actualiser la page dans le navigateur. Attention, dans certains cas, il est préférable de redémarrer le serveur.

Erreurs fréquentes

  • Lancer le serveur depuis un mauvais dossier : la commande ne trouve pas manage.py.
  • Le port 8000 est déjà utilisé : le serveur ne démarre pas.
  • Modifier settings.py sans redémarrer le serveur : les changements ne sont pas pris en compte.
