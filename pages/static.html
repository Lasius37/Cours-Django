Structure des dossiers de fichiers statiques

Les fichiers statiques sont regroupés dans un dossier static . 

Mon_Projet/
├── static/
│   ├── css/
│   │   └── style.css
│   ├── img/
│   │   └── photo.jpg
│   └── js/
│       └── script.js

Cette organisation permet de séparer clairement les types de fichiers.

Configuration des fichiers statiques

Django doit savoir où trouver les fichiers statiques. Il les trouve grâce aux lignes suivantes dans settings.py : 

STATIC_URL = "/static/"

STATICFILES_DIRS = [
    BASE_DIR / "static"
]
  • STATIC_URL : chemin utilisé dans le navigateur
  • STATICFILES_DIRS : dossiers où sont stockés les fichiers

Utilisation dans les templates

Pour utiliser un fichier statique, il faut charger la balise Django : 

{% load static }}
  • Dans un template combiné, cette balise se place juste après {% extends ... }}.
  • Dans un template de base, elle se place au début du fichier.

Ensuite, on utilise static pour construire le chemin :

  • Dans le head : 
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
  • Dans le body : 
    <img src="{% static 'img/photo.jpg' %}" alt="une photo">

Erreurs fréquentes

  • Oublier {% load static %} : fichiers non trouvés.
  • Chemin mal saisi : pas de prise en compte du fichier statique.
  • Serveur non relancé : les modifications ne sont pas prises en compte.
