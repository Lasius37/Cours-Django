Projet : la bibliothèque

    Dans cette page

    Énoncé

    Vous devez réaliser une application de bibliothèque avec Django. L’application doit permettre de gérer des livres, des auteurs, des catégories, et leurs relations, tout en affichant les données dans des pages web.

    1. Gestion des données

      • Les livres, les auteurs et les catégories sont stockés dans une base de données.
      • Un livre est caractérisé par :
        • un titre
        • une année de publication
        • une ou plusieurs catégories
        • un auteur
      • Un auteur est caractérisé par :
        • un prénom
        • un nom
      • Une catégorie est caractérisée par :
        • un nom
      • Les données sont accessibles depuis l'interface d'administration.

    2. Fonctionnement

      • L’application comporte plusieurs pages :
        • une page d’accueil
        • une page affichant la liste complète des livres
        • une page affichant la liste complète des auteurs
        • une page affichant la liste complète des catégories
        • une page affichant des informations sur un livre (auteur, catégories)
        • une page affichant des informations sur un auteur (nom, livres écrits)
        • une page affichant des informations sur une catégorie (livres)
      • Des liens permettent de naviguer dans l'ensemble du projet :
        • retour à l'accueil
        • sélection d'un livre dès que son titre apparaît
        • sélection d'une catégorie dès que son nom est affiché
        • sélection d'un auteur dès que son nom est affiché
      • Dans une même page, les éléments de même type sont affichés dans l'ordre alphabétique.
      • L’administration Django permet d’ajouter, modifier et supprimer les données.
      • L’application doit fonctionner avec le serveur de développement et afficher correctement les données de la base.

    Conseils de réalisation

    Modèles

    • Créer les modèles dans models.py.
    • Définir Book, Author et Category.
    • Ajouter les relations :
      • ForeignKey pour l’auteur ;
      • ManyToManyField pour les catégories.
    • Ajouter les méthodes __str__().

    Base de données et administration

    • Créer les migrations et les appliquer.
    • Enregistrer les modèles dans admin.py.
    • Créer un superutilisateur.
    • Ajouter des données de test :

    Vues

    • Créer les routes suivantes, les associer à des vues :
      • La route/ pour la vue "home"
      • La route/books/ pour la vue "book_list"
      • La route/books/<int:id> pour la vue "book_detail"
      • La route/authors/ pour la vue "author_list"
      • La route/authors/<int:id> pour la vue "author_detail"
      • La route/categories/ pour la vue "category_list"
      • La route/categories/<int:id> pour la vue "category_detail"
    • Utiliser des QuerySets adaptés pour chaque vue.
    • Ordonner les QuerySets (titre pour les livres, noms pour l'auteur et pour les catégories).
    • Envoyer les données avec un context.

    Templates

    • Créer les pages HTML.
    • Afficher les données nécessaires.
    • Créer un base.html commun.
    • Réaliser une mise en forme soignée.
