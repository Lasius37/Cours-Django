    Rôle d'une vue fonctionnelle

    Une vue est une fonction Python appelée lorsqu'un utilisateur demande une URL. Elle reçoit la requête du navigateur, exécute le code nécessaire, puis renvoie une réponse.

    Dans une application Django, les vues sont généralement écrites dans le fichier views.py.

    Une vue peut par exemple :

    • renvoyer un texte simple
    • afficher un template HTML
    • préparer des données avant l'affichage
    • réagir à des informations envoyées par l'utilisateur

    Créer une vue dans views.py

    On crée la vue dans le fichier views.py de l'application. Une vue fonctionnelle est une fonction classique qui prend au minimum le paramètre request. 

    from django.http import HttpResponse

def home(request):
    return HttpResponse("Bonjour depuis Django !")
    • request représente la requête HTTP reçue ;
    • home est le nom de la vue ;
    • HttpResponse permet de renvoyer une réponse simple au navigateur.

    Cette fonction peut maintenant être appelée depuis urls.py.

    Renvoyer une réponse simple

    Pour vérifier rapidement qu'une route fonctionne, on peut renvoyer un texte brut avec HttpResponse. 

    from django.http import HttpResponse

def about(request):
    return HttpResponse("Page à propos")

    Cette méthode est pratique pour tester une URL ou valider le lien entre : 

    urls.py
↓
views.py
↓
réponse envoyée au navigateur

    Renvoyer un template avec render()

    Pour afficher une vraie page HTML, on utilise généralement la fonction render(). 

    from django.shortcuts import render

def home(request):
    return render(request, "home.html")
    • request est la requête reçue ;
    • "home.html" est le template à afficher.

    La fonction render() charge le fichier HTML, puis renvoie le résultat au navigateur.

    Exemple d'organisation possible : 

    apps/
└── mon_app/
    ├── views.py
    └── templates/
        └── home.html

    Erreurs fréquentes

    • Oublier d'importer HttpResponse ou render : NameError.
    • Nommer la vue dans urls.py avec un nom différent de celui défini dans views.py : AttributeError ou erreur d'import.
    • Oublier le paramètre request dans la fonction : la vue ne peut pas être appelée correctement.
    • Indiquer un nom de template inexistant dans render() : TemplateDoesNotExist.
    • Essayer d'écrire du HTML directement dans HttpResponse pour une vraie page : code peu lisible et difficile à maintenir.
